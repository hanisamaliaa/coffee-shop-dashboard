# Coffee Shop Sales Dashboard

Capstone project for Data Analysis using the Coffee Shop Sales dataset.

##  Project Objectives

This project aims to analyze Coffee Shop Sales data and provide business insights through an interactive Streamlit dashboard.

The project includes:

- Data Quality Assessment
- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Executive Dashboard
- Business Recommendation

---

##  Tech Stack

- Python
- Streamlit
- Pandas
- Matplotlib

---

## Dashboard Pages

1. Executive Summary
2. Sales Dashboard
3. Product Dashboard
4. Customer Dashboard
5. Time Analysis
6. Business Recommendation
